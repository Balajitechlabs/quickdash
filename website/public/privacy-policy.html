1. Data Collection — NONE

QuickDash collects absolutely no personal or device data. The app runs entirely on-device. No analytics, no telemetry, no crash reporting, no user tracking of any kind is implemented. QuickDash makes zero network requests from the app itself for data collection purposes.

2. Permissions & Their Use

QuickDash requests the following permissions solely for its core functionality:

  • SYSTEM_ALERT_WINDOW (Overlay Permission): Required to display the floating tool dashboard over other applications. This is the core feature of QuickDash. No data is accessed or transmitted via this permission.
  • Camera: Used exclusively for scanning UPI QR codes for payments. Camera streams are processed entirely on-device. No images, video, or derived data are ever recorded, stored, or transmitted.
  • Media Projection / Screen Recording: Used only when you explicitly initiate screen recording or doodle annotations. Recorded media is saved locally to your device storage. No media is automatically shared or uploaded.
  • Internet: Used solely for optional features — checking for app updates (a lightweight JSON fetch), optional on-device AI model downloads (MediaPipe), and optional currency conversion rates. No personal data is transmitted.
  • Access Network State: Used to detect Wi-Fi connectivity for the Wi-Fi Share feature. This information stays on-device.
  • Post Notifications (Android 13+): Used for timer notifications. No data is collected.
  • Vibration: Used for haptic feedback on interactions. No data is collected.

3. Data Sharing — NONE

QuickDash does not share any data with third parties. The app does not integrate any third-party analytics, advertising, or tracking SDKs. All processing occurs on-device.

Third-Party Services (App & Website)

  • GitHub Releases: The APK update check fetches a static JSON file from the QuickDash website. No identifiers are included in this request.
  • GitHub Pages: The website (quickdash.balajitechlab.com) is hosted on GitHub Pages. GitHub may collect standard server logs per their privacy policy.
  • Google Analytics (Website Only): The QuickDash website uses Google Analytics (GA4) to measure anonymous page views. The app itself does not use Google Analytics. Website visitors may opt out via browser settings.
  • Telegram: The feedback form sends your message to the developer via a Telegram bot. This is an optional feature. No data is stored beyond the transmission.

4. Data Security

All optional data in transit is encrypted using HTTPS. On-device data (notes, clipboard history, settings) is stored in Android's private app storage, which is sandboxed by the operating system and inaccessible to other apps.

5. Data Retention & Deletion

Since QuickDash collects no data, there is nothing to retain or delete. Local app data (notes, clipboard history, settings) can be cleared at any time through the app's Settings or by uninstalling the application, which removes all local data.

6. Children's Privacy

QuickDash does not collect any personal information from anyone, including children under 13. If you are a parent or guardian and believe your child has provided personal data through the optional feedback form, contact us at quickdash@balajitechlab.com and we will delete it promptly.

7. Changes to This Policy
