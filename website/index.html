Frequently Asked Questions

Got questions? We've got answers.

Is root access required to run QuickDash? expand_more

No! QuickDash only uses standard Android Floating Window permission (SYSTEM_ALERT_WINDOW). It works on stock non-rooted Android 7.0 through Android 15.

How does QuickDash preserve user privacy? expand_more

QuickDash has ZERO network analytics, zero trackers, and zero cloud uploads. Everything including QR rendering, notes, and local AI uses on-device APIs like Google ML Kit.

Does it work over games and video calls? expand_more

Yes! Because QuickDash renders as a floating window layer, it stays accessible over YouTube, WhatsApp video calls, games, and banking apps.

Which APK format should I download? expand_more

If you are unsure of your phone CPU, download the Universal APK. For modern devices (Pixel 6+, Galaxy S20+, OnePlus 8+), download the ARM64-v8a APK for a smaller 25MB install size.

Privacy Policy Changelog (v5.0.0) Built with ❤️ for Android

shield Privacy Policy & Data Safety

verified
100% On-Device & Telemetry-Free

QuickDash collects ZERO personal data, transmits no analytics, and operates completely offline.

1. Zero Remote Servers

QuickDash does not connect to any tracking servers, analytics services, or cloud databases. There are no user accounts, no telemetry telemetry pings, and no crash reports sent to external vendors.

2. Local Storage (Room DB & EncryptedSharedPrefs)

All user notes, custom QR payment configurations, clipboard history entries, and app settings are stored locally on your device hardware using Android Room and Encrypted SharedPreferences.

3. Android Permission Breakdown

SYSTEM_ALERT_WINDOW (Floating Overlay): Required to render the floating bubble widget over other apps.
CAMERA (QR Code Scanner): Used exclusively to scan Wi-Fi & payment QR codes via Google ML Kit API. Never records or stores video.
FOREGROUND_SERVICE (Quick Capture): Used solely while screen recording or whiteboard annotation is active.
